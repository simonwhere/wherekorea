# 둘셋 — 둘이 셋이 되기까지

임신을 준비하는 두 사람이 **함께** 쓰는 앱의 프로토타입이에요.

- ☀️ **오늘**: 두 사람 각자의 영양제·습관 체크. 서로 진행 상황을 보고 👉 콕 찌르기, 👏 응원을 보낼 수 있어요
- 📅 **달력**: 생리 기록 → 가임기 **예상**, LH 배란테스트로 보정, 두 사람에게 알림, 폰 캘린더(.ics)로 내보내기
- 💞 **데이트**: 가임기를 '우리의 주간'으로 바꿔 데이트 아이디어와 제안 제공 (카카오맵·네이버지도 연결)
- 🤰 **임신** → 👶 **아기**: 주수·예정일·검사 일정, 백일·돌, 성장 기록, 영유아 검진
- 📔 **기록**: 준비 기록 → 태교일기 → 육아일기가 하나의 이야기로 이어져요 (HTML로 내보내기)

> 레포의 `wherekorea/` (여행 서비스)와는 **별개 프로젝트**예요. 같은 레포의 옆 폴더에 두었어요.

## 실행

```bash
cd dulset
npm install
npm run dev        # http://localhost:3000
npm test           # 로직 단위 테스트 (vitest)
npm run typecheck
npm run build      # out/ 에 정적 파일 생성 → 아무 정적 호스팅(Vercel 등)에 배포 가능
```

- 처음 화면에서 **"예시로 둘러보기"**(준비 중 / 임신 중 / 육아 중)를 누르면 데이터가 채워진 상태로 볼 수 있어요.
- 상단의 이름 버튼 **⇄**를 누르면 배우자 화면으로 바뀌어요. **브라우저 탭 두 개**를 열면 두 사람 폰처럼 동기화돼요 (같은 브라우저 저장소 사용).
- 주소 뒤에 `?today=2026-10-01`을 붙이면 날짜를 고정해서 볼 수 있어요 (데모·테스트용).

## 프로토타입의 한계 (정직하게)

| 기능 | 지금 | 실제 앱에서 필요한 것 |
|---|---|---|
| 배우자 연결 | 한 기기에서 화면 전환, 같은 브라우저의 탭끼리 동기화 | 서버(예: Supabase) + 초대 코드 수락 + 연결 해제 흐름 |
| 두 사람에게 알림 | 앱 안 알림함 + (앱을 열어 둔 동안) 브라우저 알림 + **.ics 캘린더 알람** | 푸시 서버 (Capacitor 앱이면 FCM/APNs) |
| 데이터 | 이 기기에만 저장 (localStorage, 사진은 IndexedDB) | 암호화 저장, 민감정보 별도 동의, 백업 |
| 가임기 | 달력법 + LH 보정 **추정치** | 동일 (의료기기가 아님을 유지). 식약처 해당 여부 질의 권장 |

## 구조

```
app/                 Next.js App Router (정적 export, 한 페이지 + 해시 탭 라우팅)
components/
  AppShell.tsx       상단 바, 하단 탭(단계별로 바뀜), 알림 엔진 연결
  Onboarding.tsx     시작 흐름 + 예시 데이터
  tabs/*.tsx         오늘 · 달력 · 데이트 · 기록 · 임신 · 아기 · 설정
  ui/index.tsx       공통 UI (Card, Button, Sheet, Toast …)
lib/
  types.ts           도메인 타입
  store.tsx          상태 + 저장 (useApp)
  logic/*.ts         순수 함수 로직 — cycle(가임기), checks, notifications, pregnancy, baby, diary, ics …
  content/*.ts       콘텐츠 — 정부 지원사업, 영양제 근거, 데이트 아이디어, 주수별 정보 …
tests/*.test.ts      로직 단위 테스트
docs/research.md     시장·의학 근거·규제 조사 ("이런 앱이 이미 있나?")
```

상태 변경은 모두 `update(s => 순수함수(s, …))` 형태예요. 로직은 `lib/logic`에 있고 테스트로 검증해요.

## 설계 원칙

1. **부담 주지 않기**: 배란일에 맞춘 관계는 스트레스와 성기능 저하와 연관돼요. 그래서 알림 방식을 **각자** 골라요(직접적 / 은근하게 / 끄기). '부담 줄이기 모드'(NICE 2026: 주기 내내 2~3일마다)도 있어요. 금지어: 숙제, 실패, "오늘 꼭".
2. **예측은 예상치**: 달력 계산은 부정확해요(가임기가 교과서 구간에 들어오는 여성 약 30%). 모든 날짜에 '예상'을 붙이고, 불확실성 범위와 LH 테스트를 안내해요. 피임·진단 용도가 아니에요.
3. **남편도 행동하기**: 남성 아연·엽산 영양제는 효과가 없었어요(FAZST 2020). 그래서 금주·금연·사우나 피하기와 74일 정자 생성 타이머를 둬요.
4. **민감정보는 기기 밖으로 보내지 않기**: 광고·분석 SDK 없음. 내보내기와 전체 삭제 제공.

근거와 출처는 [`docs/research.md`](docs/research.md)에 있어요.
