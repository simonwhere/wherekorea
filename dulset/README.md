# 둘셋 — 둘이 셋이 되기까지

아기를 기다리는 두 사람이 **함께** 쓰는 앱의 프로토타입이에요. 임신 준비부터 출산 뒤까지 챙겨야 할 병원·검사·신청을 둘이 같이 챙기고, 연애 시절부터 아기가 태어난 뒤까지 둘이 쌓는 기록장이 한 앱에 이어져요.

- ☀️ **오늘**: 두 사람 각자의 영양제·습관 체크. 서로 진행 상황을 보고 👉 콕 찌르기, 👏 응원을 보낼 수 있어요. 인사 옆에 **함께한 지 D+N**, 바로 아래 **다가오는 일정**(2주 안, 2개)과 **이번 주 챙길 것**(3개, 바로 체크), 기념일 당일엔 "오늘은 우리의 날" 배너가 떠요
- ✅ **챙길 것**: 임신 준비 → 임신 초기·중기·후기 → 출산 직후 → 출산 후까지 병원·검사·예방접종·회사 제도·행정 기한을 **누가(임신하는 사람 / 배우자 / 둘이 함께)** 챙길지와 함께 보여 줘요. 마지막 생리일·예정일·출생일이 생기면 날짜가 자동으로 계산돼요. 직접 할 일을 더하고, **병원 예약**을 잡으면 전날·당일에 알려 줘요 (.ics로 폰 캘린더에도)
- 💑 **우리**: 비트윈처럼 둘이 쌓는 기록장. 만난 날부터 **함께한 지 D+N**, 100일 단위·N주년·결혼 N주년 자동 기념일과 우리만의 기념일(7일 전·당일 알림), 사진 앨범, 연애 → 준비 → 임신 → 육아로 이어지는 이야기와 짧은 마음 표시(리액션). 전부 **무료로 내보낼 수 있어요**
- 📅 **달력**: 생리 기록 → 가임기 **예상**, LH 배란테스트로 보정, 두 사람에게 알림, 폰 캘린더(.ics)로 내보내기
- 💞 **데이트**: 가임기를 '우리의 주간'으로 바꿔 데이트 아이디어와 제안 제공 (카카오맵·네이버지도 연결)
- 🤰 **임신** → 👶 **아기**: 주수·예정일·검사 일정, 백일·돌, 성장 기록, 영유아 검진 (챙길 것과 같은 체크를 함께 써요)
- ⚙️ **설정**(위쪽 톱니바퀴): 우리 둘 · 우리 둘의 날(만난 날·결혼한 날) · 연결 · 단계 · 알림 · 백업/복원

하단 탭은 단계마다 바뀌어요: 준비 중 `오늘 · 달력 · 챙길 것 · 데이트 · 우리`, 임신 중 `오늘 · 임신 · 챙길 것 · 데이트 · 우리`, 육아 중 `오늘 · 아기 · 우리 · 챙길 것 · 둘만의`.

> 레포의 `wherekorea/` (여행 서비스)와는 **별개 프로젝트**예요. 같은 레포의 옆 폴더에 두었어요.

## 실행

```bash
cd dulset
npm install
npm run dev        # http://localhost:3000
npm test           # 로직 단위 테스트 (vitest)
npm run typecheck
npm run build      # out/ 에 정적 파일 생성 → 아무 정적 호스팅(Vercel 등)에 배포 가능
```

- 처음 화면에서 **"예시로 둘러보기"**(준비 중 / 임신 중 / 육아 중)를 누르면 데이터가 채워진 상태로 볼 수 있어요. 예시 커플 민수·지은은 2021-05-14에 만나 2024-10-19에 결혼했어요. 연애 시절 기록, 기념일, 병원 예약, 챙긴 항목까지 단계별로 들어 있어요.
- 상단의 이름 버튼 **⇄**를 누르면 배우자 화면으로 바뀌어요. **브라우저 탭 두 개**를 열면 두 사람 폰처럼 동기화돼요 (같은 브라우저 저장소 사용).
- 주소 뒤에 `?today=2026-10-01`을 붙이면 날짜를 고정해서 볼 수 있어요 (데모·테스트용). 예: 준비 중 예시에 `?today=2026-10-03`이면 '첫 여행 5주년' 배너가 보여요.

## 챙길 것 콘텐츠의 원칙

- 모든 항목에 출처가 있고, 법·제도는 **시행일**을 함께 적어요. 예: 배우자 출산휴가 20일(2025-02-23부터, 2026-09-18부터는 예정일 50일 전부터 사용), 출산전후휴가는 예정일 44일 전 이후 시작, 산후도우미 바우처는 예정일 40일 전 ~ 출산 후 60일, 출생신고 1개월, 부모급여·아동수당은 출생일 포함 60일 안 신청.
- 금액·조건은 해마다 바뀌고 **병원·회사·보건소마다 다를 수 있어요**. 화면에 확인일(`ROADMAP_CHECKED_AT`)과 "담당 의료진·회사·보건소에 확인" 안내를 늘 붙여요.
- 진단이나 피임 판단은 하지 않아요. 태아보험·산후조리원은 제도와 일반 정보만 싣고 상품은 추천하지 않아요.

## 프로토타입의 한계 (정직하게)

| 기능 | 지금 | 실제 앱에서 필요한 것 |
|---|---|---|
| 배우자 연결 | 한 기기에서 화면 전환, 같은 브라우저의 탭끼리 동기화 | 서버(예: Supabase 서울 리전) + 초대 코드 수락 + 연결 해제 흐름 |
| 두 사람에게 알림 | 앱 안 알림함 + (앱을 열어 둔 동안) 브라우저 알림 + **.ics 캘린더 알람** (가임기, 병원 예약) | 푸시 서버 (Capacitor 앱이면 FCM/APNs) |
| 데이터 | 이 기기에만 저장 (localStorage, 사진은 IndexedDB). 백업(.json)과 '우리 이야기' HTML 내보내기는 무료 | 로컬 우선 + 종단간 암호화 동기화, 민감정보 별도 동의 |
| 가임기 | 달력법 + LH 보정 **추정치** | 동일 (의료기기가 아님을 유지). 식약처 해당 여부 질의 권장 |
| 챙길 것 | 앱에 들어 있는 콘텐츠(확인일 2026-09-26) | 서버에서 시행일·출처와 함께 관리, 거주지별 지자체 사업 분리 |

```
app/                 Next.js App Router (정적 export, 한 페이지 + 해시 탭 라우팅)
components/

  Onboarding.tsx     시작 흐름 (우리 둘 단계에서 만난 날·결혼한 날도 받아요) + 예시 데이터
  tabs/*.tsx         오늘 · 달력 · 챙길 것(PlanTab) · 데이트 · 우리(UsTab, 해시는 #diary) · 임신 · 아기 · 설정
  today/             오늘 카드들 — PlanCards(다가오는 일정·이번 주 챙길 것), AnniversaryBanner, model.ts(순수 규칙)
  plan/              챙길 것 — 이번 주, 병원 예약, 단계별 목록, 직접 추가 (model.ts가 화면 규칙)
  us/                우리 — 함께한 날수, 이야기·앨범·기념일, 내보내기
  settings/          설정 섹션들 (우리 둘의 날, 데이터와 개인정보 …)
  ui/index.tsx       공통 UI (Card, Button, Sheet, Toast …)
lib/
  types.ts           도메인 타입 (Couple.metDate/marriedDate, Appointment, CustomTask, planDone …)
  store.tsx          상태 + 저장 (useApp)
  logic/*.ts         순수 함수 로직 — cycle(가임기), checks, notifications, pregnancy, baby, diary,
                     roadmap(챙길 것), appointments(병원 예약·알림), anniversary(기념일), usView(우리), ics …
  content/*.ts       콘텐츠 — roadmap(챙길 것 항목·출처), 정부 지원사업, 영양제 근거, 데이트 아이디어, 주수별 정보 …
  demo.ts            온보딩 도우미 + "예시로 둘러보기" 데이터 (앱과 같은 순수 함수로 만들어요)
tests/*.test.ts      로직 단위 테스트
docs/research.md     시장·의학 근거·규제 조사 ("이런 앱이 이미 있나?")

```

상태 변경은 모두 `update(s => 순수함수(s, …))` 형태예요. 로직은 `lib/logic`에 있고 테스트로 검증해요. 기념일·병원 예약·챙길 것 진행 상황도 상태의 일부라 백업 파일에 함께 들어가요.

## 설계 원칙

1. **부담 주지 않기**: 배란일에 맞춘 관계는 스트레스와 성기능 저하와 연관돼요. 그래서 알림 방식을 **각자** 골라요(가임기라고 알려 주세요 / ‘우리의 주간’처럼 은근하게 / 받지 않을래요). '부담 없이 모드'(NICE 2026: 주기 내내 2~3일마다)도 있어요. 금지어: 숙제, 실패, "오늘 꼭". 챙길 것도 급한 게 없으면 "여유 있을 때 살펴봐요"로 조용히 보여 줘요.
2. **예측은 예상치**: 달력 계산은 부정확해요(가임기가 교과서 구간에 들어오는 여성 약 30%). 모든 날짜에 '예상'을 붙이고, 불확실성 범위와 LH 테스트를 안내해요. 피임·진단 용도가 아니에요.
3. **남편도 행동하기**: 남성 아연·엽산 영양제는 효과가 없었어요(FAZST 2020). 그래서 금주·금연·사우나 피하기와 정자 형성 타이머(약 64~74일 + 성숙 1~2주, 모두 3개월쯤)를 두고, 챙길 것에서도 배우자 몫(정액검사, Tdap, 배우자 출산휴가 …)을 따로 보여 줘요.
4. **민감정보는 기기 밖으로 보내지 않기**: 광고·분석 SDK 없음. 내보내기와 전체 삭제 제공.
5. **기록은 볼모가 아니다**: 비트윈 사진 삭제 사고(2025-09)의 교훈으로, 기록장 내보내기는 언제나 무료예요. 1:1 채팅은 넣지 않고(대화는 이미 카카오톡에서 해요) 기록에 짧은 리액션만 남겨요. 서버 원칙은 [`docs/next-steps.md`](docs/next-steps.md)에 있어요.

근거와 출처는 [`docs/research.md`](docs/research.md)에 있어요.
