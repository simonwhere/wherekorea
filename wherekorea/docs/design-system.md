# Design System Direction — WhereKorea

## Product feel
WhereKorea should look like a trustworthy information product, not a tourism brochure.

## Keywords
- clean
- sharp
- map as context
- card-first
- calm
- easy to scan
- low cognitive load

## Homepage
- cards must remain visually primary
- map must support geography and distance intuition
- filters must be visible without dominating the screen

## Cards
- compact and readable
- avoid overstuffing
- hierarchy should be obvious:
  1. name
  2. vibe
  3. stay
  4. weather snapshot
  5. budget
  6. tags

## Detail pages
- should feel like a decision page, not a blog post
- use section blocks and visual rhythm
- food belongs in v1, but should stay curated and compact

## Map rule
Use map visuals freely in exploration, but standardize into structured SVG/vector assets when the layout is validated.
