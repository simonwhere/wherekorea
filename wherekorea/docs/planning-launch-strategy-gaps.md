# 런칭 전 전략 갭 — Nomad List 등과 "전략" 레벨 비교 (2026-07-12)

> ✅ **S2~S5 실행 완료 (2026-07-12):**
> S2 → `/about` (방법론·출처·₩/day 정의·랭킹 원리) + 전 페이지 Footer("About & data methodology" 링크)
> S3 → 코어 페르소나 PROJECT-BRIEF §1에 명문화 (영어권·1~2주·서울+2~3도시)
> S4 → `/api/weekly-post` — 라이브 데이터로 "This Week in Korea" 텔레그램 포스트 자동 생성 (Top5+축제+peak 경보, 실검증 완료). Footer에 채널 링크 자리(`NEXT_PUBLIC_TELEGRAM_URL`). **채널 개설은 승익 몫.**
> S5 → `track()` → Plausible 연동 (배포 시 `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` 설정하면 활성, 미설정 시 무해).
> 남은 것: S1 (메타/OG/schema/sitemap — 다음 세션) · 텔레그램 채널 개설 · Plausible 가입+도메인.

> 기능(G-A~F)은 구현 완료. 여기서는 기능이 아니라 **전략** — 유통·신뢰·타깃·리텐션·수익 — 을 본다.
> 결론 한 줄: **제품은 런칭 가능 수준, 전략의 병목은 "아무도 모른다"는 것.**

## S1. 유통 제로 ⭐ 최대 갭
- Nomad List의 진짜 모트는 기능이 아니라 **유통**이었다: 창업자(levelsio)의 빌드인퍼블릭 트위터 + 커뮤니티가 무료 유통망.
- 우리 현황: SEO 기본(메타/OG/sitemap) 미구현 · GEO(schema.org) 미구현 · 텔레그램 채널 미개설 · 소셜 부재.
- 런칭 = 배포가 아니라 유통 개시. **런칭 주간 패키지: ① 메타/OG/sitemap ② schema.org ③ 텔레그램 채널 개설+주간 포스트 ④ r/koreatravel 등에 도구로서 소개(스팸 아닌 답변 속 링크).**

## S2. 신뢰의 가시화 부족
- 데이터 신뢰 구조(trust 메타, 방문자 데이터 검증)를 만들어놓고 **사용자에게 안 보여준다.** Nomad List는 "1M+ data points"를 전면에 과시.
- 필요: About/방법론 페이지 1장 — 누가, 왜, 데이터가 어디서(KT/SKT 방문자·open-meteo·TourAPI), 숫자의 정의(₩/day 바스켓). AI 시대 신뢰 = 출처 공개. detail 하단에 "data sources" 한 줄 + 링크.

## S3. 타깃이 넓다
- Nomad List = "디지털 노마드"라는 칼같은 니치. 우리는 "외국인 한국 여행자" 전체.
- 제안: **"첫 한국 여행, 1~2주, 서울+2도시를 고르는 서양 여행자"**를 코어 페르소나로 명문화 → 카피/기본 정렬/추천 매치업의 기준이 됨. (일본·중국어권은 방한 1~2위 시장이지만 언어 확장은 v2 질문으로.)

## S4. 리텐션 루프 약함
- 여행 준비는 수 주 — 그동안 다시 올 이유가 저장(♡)뿐.
- 텔레그램 채널이 1차 루프. 2차 후보: "내 여행 날짜 선택 → 그 주의 Best" (G-D 재랭킹과 자연 결합, 오픈 후).

## S5. 측정 미가동 (런칭 블로커급)
- `track()`이 스텁. 런칭일부터 유입/행동 데이터 유실. Plausible/Umami 하나 붙이는 데 반나절.

## S6. 수익 경계 미정 (지금 결정은 불요, 경계만)
- non-goal에 예약·결제. 단 "제휴 링크아웃"(숙소/투어 아웃링크) 허용 여부는 경계가 모호 — 무료 유지 + 링크아웃 없음으로 v1 고정하고, v2에서 재논의 권장 (신뢰 자산 보호).

## V. 가시성/폰트 진단
- **폰트 교체는 불필요** — 문제는 폰트가 아니라 셋:
  1. **영문 제품인데 본문 폰트 1순위가 Pretendard(한글 최적화)** — Inter를 1순위로 스왑 (한글 표기는 Pretendard가 fallback으로 계속 담당)
  2. **저대비 텍스트 43곳** (white/35~45 라벨 다수 — 작은 글씨 WCAG 4.5:1 경계선)
  3. **극소 텍스트 7곳** (8.5~10px)
- 조치: 폰트 순서 스왑(적용) + Tailwind 라벨 대비 한 단계 업(적용). 인라인 스타일 대비/스케일 미세조정과 헤딩 디스플레이 폰트 실험(원하면 Space Grotesk 류)은 VS Code에서 눈으로.
