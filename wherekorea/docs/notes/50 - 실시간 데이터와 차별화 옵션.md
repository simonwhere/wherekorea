# 50 - 실시간 데이터와 차별화 옵션

## 실시간 데이터 (무료 공공데이터)
우선순위순:
- **★ 혼잡도** — 한국관광공사 TourAPI (KT 이동통신 30일 예측 + 티맵). static `crowd_friction` 대체. "지금 한산한 곳" 랭킹의 핵심.
- **날씨** — open-meteo, 이미 연동됨. 랭킹에 쓰기만.
- **축제/행사** — TourAPI 날짜별. "지금 가야 할 이유".
- **미세먼지** — 에어코리아 PM10/PM2.5 + 예보.
- 교통 실시간 = 난이도 높아 보류.

> `lib/weather.ts`에 이미 **fallback 패턴** 있음 → live 실패해도 화면 안 깨짐. 신규 소스도 동일하게.

## 차별화 옵션 (데이터 위에 얹는 것)
1. **타이밍 — "지금 vs 2주 뒤"** (블로그가 못 하는 것)
2. **동적 why-now / skip-now 카피**
3. **"지금 가장 한산한 곳"** (실데이터 기반)
4. **이번 주 축제 어웨어**
5. **여정 형태 재랭킹** (from-Seoul/무차/일수)
6. **주간 알림** ("제주 미세먼지 나쁨 → 강릉")

⚠️ 모두 "결정을 돕는" 방향. 예약·itinerary·디렉토리·커뮤니티로 새지 않기.
