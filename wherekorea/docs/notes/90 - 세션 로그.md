# 90 - 세션 로그

> 우리가 이 세션에서 나눈 대화 흐름 기록. 나중에 "왜 이렇게 정했지?" 할 때 참고.

1. **프로젝트 검토 요청** — 폴더 연결(처음엔 빈 `wherekorea (1)` → 실제 `wherekorea` 재연결).
2. **코드 검증** — master-detail 이미 구현됨 확인, `tsc` clean. 문서 vs 코드 갭 도출 → [[20 - 현재 상태와 갭]], `STATUS-and-NEXT.md` 작성.
3. **수정할 것 정리** — G1~G5. skill 문서 없던 문제(G3) 발견.
4. **skill 파일 5개 생성** — `docs/skills/` (06,07,08,10,11), CLAUDE.md/AGENTS.md 참조 정리.
5. **필터 방향 논의** — 잡지형 vs 필터형 차이 설명 → "Best now 랭킹 디폴트 + FilterStrip 좁히기"로 결정. [[30 - 핵심 결정들]]
6. **협업 방식 명확화** — 여기 기획 / VS Code 코딩. [[60 - 협업 방식 (여기 + VS Code)]]
7. **영속 컨텍스트 세팅** — `PROJECT-BRIEF.md` + CLAUDE.md 포인터 + Cowork 메모리.
8. **검수** — 정체성/협업 규칙이 어디서 나왔는지 출처 확인 (당신 자료 + 이 대화).
9. **데이터·차별화 기획** — 실시간 공공데이터(혼잡도/축제/미세먼지) + 차별화 옵션 정리. [[50 - 실시간 데이터와 차별화 옵션]]. 핵심: Best Now 랭킹이 미구현 → [[40 - Best Now 랭킹 (핵심 IP)]].
10. **옵시디언 정리** — 이 노트들 생성.
