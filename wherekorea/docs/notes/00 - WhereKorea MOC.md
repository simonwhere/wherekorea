# 🗺️ WhereKorea — 시작 노트 (MOC)

> 이 노트가 입구예요. 아래 링크를 **클릭**하면 해당 노트로 이동합니다.
> (옵시디언에서 `Cmd/Ctrl + 클릭` 또는 그냥 클릭)

## 핵심 노트
- [[10 - WhereKorea란]] — 제품이 뭔지 한 장
- [[20 - 현재 상태와 갭]] — 지금 코드가 어디까지 됐나
- [[30 - 핵심 결정들]] — 우리가 합의한 것들
- [[40 - Best Now 랭킹 (핵심 IP)]] — 제품의 진짜 차별화
- [[50 - 실시간 데이터와 차별화 옵션]] — 경쟁력 올릴 데이터
- [[60 - 협업 방식 (여기 + VS Code)]] — 어떻게 일하나
- [[70 - 다음 할 일]] — 다음 액션
- [[90 - 세션 로그]] — 우리 대화 흐름 기록

## 실제 프로젝트 문서 (코드 폴더 안)
이것들도 같은 vault라 클릭으로 열려요:
- [[PROJECT-BRIEF]] — 단일 기준 문서 (세션 시작 시 먼저 읽는 것)
- [[STATUS-and-NEXT]] — 코드 검증 결과 + 갭
- [[planning-data-and-differentiation]] — 데이터/차별화 기획
- [[handoff-G1-filter]] — VS Code에 넘기는 필터 작업 지시문

## 옵시디언 30초 사용법
1. 옵시디언 열기 → **"Open folder as vault"** → `wherekorea` 폴더 선택.
2. 왼쪽 파일목록에서 `notes/00 - WhereKorea MOC` 열기.
3. `[[파란 링크]]` 클릭하며 돌아다니기. 끝.
