# 40 - Best Now 랭킹 (핵심 IP)

## 발견한 문제
홈 헤드라인은 *"Ranked by season, weather, crowd level and travel time"* 인데,
실제 코드(`matchesCategory('best-now')`)는 `return true` — **정렬이 없음.** 그냥 10개를 데이터 순서대로 보여줌.
즉 제품의 핵심 약속이 **카피로만 있고 구현은 없음.** live weather도 받아오기만 하고 랭킹에 안 씀.

## 왜 중요한가
이게 블로그·관광청과 다른 **유일한 이유**. "글이 아니라 *지금 조건에 맞는 순위*를 준다."

## 제안 점수 (튜닝 대상)
```
best_now_score =
    날씨 적합도   (계절·기온·강수)
  + 낮은 혼잡     (실시간 혼잡도)
  + 대기질 양호   (미세먼지)
  + 축제 보너스   (지금 갈 만한 행사)
  + 접근 용이     (from-Seoul / no-car)
  - 비수기 페널티
```
→ 이 점수로 'Best now' 정렬. 카드/preview에 "왜 지금 상위인지" 한 줄을 **동적 생성**("맑고 한산함 · 벚꽃축제 중").
